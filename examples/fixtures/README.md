# Vision server smoke fixtures

Drop any `.jpg`/`.png` specimen photos here for the local smoke entrypoint
(`modal run server/app.py`). The entrypoint looks for
`pseudo-sanderiana-1.jpg` (subject) plus `pseudo-sanderiana-2.jpg` and
`pseudo-sanderiana-3.jpg` (few-shot references), but any plant photos with
those names will do. Image binaries are intentionally not tracked by git.
